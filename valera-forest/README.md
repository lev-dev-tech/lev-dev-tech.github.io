# Лес Валеры: серия 1

Вертикальное видео 1080x1920, 30 fps, Remotion + TypeScript.

## Запуск

```bash
npm install
npm run studio
npm run render
```

Рендер кладёт файл в `out/video.mp4` (H.264, CRF 18).

## Структура

- `src/scenes.ts` содержит все тайминги: сцены, биты, реплики, звуки, шкалу страха и часы.
- `src/scenes/S0Intro.tsx … S8Finale.tsx`: по компоненту на каждую сцену сценария.
- `src/characters/Character.tsx`: Артём, Алина и Валера. Эмоции и позы переключаются пропсами `emotion` и `pose`.
- `src/characters/Creatures.tsx`: волк (`Wolf`, `WolfFace`), чудовище, белка, красные глаза.
- `src/env`: лес (ночь / тьма / утро, параллакс, туман), спальня, святилище, кристаллы, воронка.
- `src/ui`: плашка времени, стикер СТРАХ, субтитры, полароид, штамп, бейдж, облако мыслей, телефон, видоискатель.
- `scripts/sfx.py`: синтез звуковых эффектов и эмбиента в `audio/sfx`. Копия лежит в `public/audio/sfx`.
- `scripts/stills.mjs` и `scripts/frames.mjs`: стоп-кадры для проверки.

## Озвучка

В `./audio` нет файлов озвучки, поэтому реплики идут только субтитрами.
Время показа считается так: 3 слова в секунду плюс 0,5 секунды на реплику.
Если появится озвучка, тайминги реплик меняются в `src/scenes.ts`.

## Звуки

```bash
python3 scripts/sfx.py audio/sfx && cp audio/sfx/* public/audio/sfx/
```
